## Behind the Handle

I'm Muhammad, known online as **Beri Contraster**, an offensive security professional with [**OSCP**](https://www.credential.net/677f4c26-3f2b-4a12-9b14-dbb45565d6a8#acc.BstT7jig) and **CPTS** certifications. I test web applications, APIs, Active Directory, cloud environments, and internal networks, tracing how individual weaknesses connect into realistic attack paths and translating the findings into clear risks and practical remediation.

I build vulnerable labs and training environments, write technical walkthroughs, and share what I learn from security research and CTFs. My repositories and [blog](https://bericontraster.com/blog) document the process behind the result: what I tested, why a technique worked, and what the experience taught me.

## Projects

### Offensive Security Curriculum Architecture

Developed two offensive security courses comparable in scope to PNPT, covering web application security, Active Directory, and AI exploitation. Designed the final practical examinations, managed global certification issuance, and personally trained **50+ students and corporate professionals** in real-world adversary tactics, techniques, and procedures.

### Enterprise Compliance Architecture: ACSC Essential Eight

Built most of the backend and designed the security architecture for an enterprise application that automated **ACSC Essential Eight compliance** workflows. The platform included admin and user dashboards to support compliance management for enterprise clients.

### Real-Time AI Vishing & Voice Synthesis Engine

Co-developed a voice-phishing simulation platform using **ElevenLabs, Twilio, and AI models**. Combined voice synthesis and automated calling campaigns to simulate realistic social engineering attacks for client security awareness training.

### Active Directory Training Labs: BlackSite

Engineered vulnerable Active Directory environments that mirror architectural flaws in enterprise networks. Authored exploitation guides that connect the underlying vulnerabilities to practical attack techniques, giving aspiring security professionals hands-on training scenarios.

- **Focus areas:** Kerberoasting, ACL abuse, constrained delegation, and complex cross-forest escalation paths.
